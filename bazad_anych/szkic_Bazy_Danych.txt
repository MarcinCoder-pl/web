 _________________users_____________________________________________________________________
| Kolumna              | Typ danych     | Opis                                      		|
| -------------------- | -------------- | --------------------------------------------------|
| `id`                 | `INT`          | Unikalny identyfikator (klucz główny)     		|
| `username`           | `VARCHAR(50)`  | Unikalna nazwa użytkownika                		|
| `email`              | `VARCHAR(100)` | Unikalny adres e-mail                     		|
| `password_hash`      | `VARCHAR(255)` | Haszowane hasło użytkownika               		|
| `first_name`         | `VARCHAR(50)`  | Imię użytkownika (opcjonalne)             		|
| `last_name`          | `VARCHAR(50)`  | Nazwisko użytkownika (opcjonalne)         		|
| `created_at`         | `DATETIME`     | Data rejestracji                          		|
| `updated_at`         | `DATETIME`     | Data ostatniej modyfikacji danych         		|
| `is_active`          | `TINYINT(1)`   | Czy konto jest aktywne (1 = tak, 0 = nie) 		|
| `role`               | `VARCHAR(20)`  | Rola użytkownika, np. `user`,`admin`,`vip`		|
| `email_verified`     | `TINYINT(1)`   | Czy adres e-mail został potwierdzony      		|
| `verification_token` | `VARCHAR(255)` | Token do weryfikacji e-maila (tymczasowy) 		|
| `reset_token`        | `VARCHAR(255)` | Token do resetowania hasła                		|
| `reset_token_expiry` | `DATETIME`     | Data wygaśnięcia tokenu resetowego        		|
| `avatar_url` 		   | `VARCHAR(255)` | Ścieżka lub URL do zdjęcia profilowego użytkownika|
|___________________________________________________________________________________________|

 _________sessions________________________________________________________________________________________
| Kolumna         | Typ danych     | Opis                                                                 |
| --------------- | -------------- | -------------------------------------------------------------------- |
| `id`            | `INT`          | Klucz główny sesji                                                   |
| `user_id`       | `INT`          | ID użytkownika z tabeli `users`                                      |
| `session_token` | `VARCHAR(255)` | Token sesyjny (np. JWT, UUID)                                        |
| `ip_address`    | `VARCHAR(45)`  | Adres IP użytkownika                                                 |
| `user_agent`    | `TEXT`         | Dane o przeglądarce i systemie                                       |
| `created_at`    | `DATETIME`     | Czas utworzenia sesji                                                |
| `expires_at`    | `DATETIME`     | Czas wygaśnięcia sesji                                               |
| FOREIGN KEY     | -              | `user_id` powiązany z `users(id)` – usuwa sesje przy usunięciu konta |
|_________________________________________________________________________________________________________|

 _______login_attempts___________________________________________________________________________________________
| Kolumna             | Typ danych     | Opis                                                                    |
| ------------------- | -------------- | ----------------------------------------------------------------------- |
| `id`                | `INT`          | Klucz główny                                                            |
| `user_id`           | `INT`          | Odniesienie do `users.id` (może być NULL jeśli użytkownik nie istnieje) |
| `email_or_username` | `VARCHAR(100)` | To, co użytkownik wpisał jako login                                     |
| `success`           | `TINYINT(1)`   | Czy logowanie się powiodło (1 = tak, 0 = nie)                           |
| `ip_address`        | `VARCHAR(45)`  | Adres IP użytkownika                                                    |
| `user_agent`        | `TEXT`         | Dane o przeglądarce i systemie                                          |
| `attempt_time`      | `DATETIME`     | Czas próby logowania                                                    |
| `error_message`     | `TEXT`         | Wiadomość o błędzie (np. do celów logów, nie użytkownika)               |
|________________________________________________________________________________________________________________|

 _account_locks____________________________________________________
| Kolumna     | Typ danych | Opis                                  |
| ----------- | ---------- | ------------------------------------- |
| `id`        | `INT`      | Klucz główny                          |
| `user_id`   | `INT`      | Użytkownik                            |
| `locked_at` | `DATETIME` | Kiedy zablokowano                     |
| `unlock_at` | `DATETIME` | Kiedy można odblokować                |
| `reason`    | `TEXT`     | Powód (np. zbyt wiele prób logowania) |
|__________________________________________________________________|

____user_settings___________________________________________________________
| Kolumna        | Typ danych    | Opis                                     |
| -------------- | ------------- | ---------------------------------------- |
| `user_id`      | `INT`         | Klucz główny, jednocześnie FK do `users` |
| `language`     | `VARCHAR(10)` | `pl`, `en`, itd.                         |
| `dark_mode`    | `TINYINT(1)`  | 0 = jasny, 1 = ciemny                    |
| `email_notify` | `TINYINT(1)`  | Czy chce otrzymywać powiadomienia e-mail |
| `timezone`     | `VARCHAR(50)` | Np. `Europe/Warsaw`                      |
| `created_at`   | `DATETIME`    | Data utworzenia ustawień                 |
|___________________________________________________________________________|

 ___audit_logs_____________________________________________________________________________
| Kolumna     | Typ danych     | Opis                                                      |
| ----------- | -------------- | --------------------------------------------------------- |
| `id`        | `INT`          | Klucz główny                                              |
| `user_id`   | `INT`          | Kto wykonał operację                                      |
| `action`    | `VARCHAR(100)` | Np. `login`, `logout`, `update_profile`, `delete_account` |
| `details`   | `TEXT`         | Dodatkowe informacje                                      |
| `created_at`| `DATETIME`     | Data operacji                                             |
|__________________________________________________________________________________________|

 ___system_messages_______________________________________________________________________
| Kolumna      | Typ danych     | Opis                                                    |
| ------------ | -------------- | ------------------------------------------------------- |
| `id`         | `INT`          | Klucz główny                                            |
| `user_id`    | `INT`          | Użytkownik, do którego skierowano wiadomość             |
| `title`      | `VARCHAR(255)` | Tytuł wiadomości (np. „Zmiana hasła”, „Nowy regulamin”) |
| `message`    | `TEXT`         | Treść wiadomości                                        |
| `type`       | `VARCHAR(50)`  | Np. `info`, `warning`, `error`, `alert`, `update`       |
| `is_read`    | `TINYINT(1)`   | Czy użytkownik przeczytał wiadomość                     |
| `created_at` | `DATETIME`     | Kiedy została wysłana                                   |
| `read_at`    | `DATETIME`     | Kiedy została przeczytana (NULL jeśli nieprzeczytana)   |
|_________________________________________________________________________________________|

 ____error_messages________________________________________________________________
| Kolumna      | Typ danych    | Opis                                              |
| ------------ | ------------- | ------------------------------------------------- |
| `id`         | `INT`         | Klucz główny                                      |
| `error_code` | `VARCHAR(50)` | Unikalny kod błędu, np. `INVALID_CREDENTIALS`     |
| `context`    | `VARCHAR(50)` | Opcjonalnie: kontekst, np. `registration`, `auth` |
| `created_at` | `DATETIME`    | Data dodania błędu                                |
|__________________________________________________________________________________|

 ___error_translations______________________________________________
| Kolumna         | Typ danych   | Opis                             |
| --------------- | ------------ | -------------------------------- |
| `id`            | `INT`        | Klucz główny                     |
| `error_id`      | `INT`        | FK do `error_messages(id)`       |
| `language_code` | `VARCHAR(5)` | Kod języka, np. `pl`, `en`, `cs` |
| `message`       | `TEXT`       | Przetłumaczony komunikat błędu   |
| `created_at`    | `DATETIME`   | Data dodania tłumaczenia         |
|___________________________________________________________________|
